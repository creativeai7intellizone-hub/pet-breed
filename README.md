# GoldenGuide — The Complete Golden Retriever Resource

> Food safety checker, feeding calculator, symptom checker, health guide & first-year cost calculator.

**GoldenGuide** is the ultimate free resource for Golden Retriever owners — covering **food safety, health, training, grooming, and costs** with interactive tools.

## ✨ Features

- 🍖 **Food safety checker** — instantly check if a food is safe or toxic
- ⚖️ **Feeding calculator** — portion sizes by age & weight
- 🩺 **Symptom checker** — know when to call the vet
- 💰 **First-year cost calculator** — budget for your new puppy
- 🎾 **Training tips** — proven positive-reinforcement methods
- 📱 **Beautiful, responsive design** — paw-some on every device

## 🛠️ Built With

- HTML5 + CSS3 + vanilla JavaScript
- No frameworks, blazing fast
